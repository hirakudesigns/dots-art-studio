# DOTS Balance Bridge (for Mac)

手元のMacとWiiバランスボードを接続し、体重移動をキーボード信号(`←` / `→`)に変換して、ブラウザのブロック崩しゲームを体感型アトラクションにするためのブリッジツールです。

## ⚙️ セットアップ手順

### 1. 事前準備 (Mac環境)
Macに `Node.js` がインストールされている必要があります。まだの場合は Homebrew や公式サイトからインストールしてください。

また、Macでネイティブなキーボード入力をエミュレートするため、初回起動時にMacから「アクセシビリティ（プライバシーとセキュリティ）」の許可を求められます。画面の指示に従ってターミナルまたはアプリを許可してください。

### 2. ライブラリのインストール
このフォルダをMacのターミナルで開き、以下のコマンドを実行します。
```bash
npm install
